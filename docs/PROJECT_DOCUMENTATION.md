# AI-Based Disaster Relief Demand Prediction System

## Complete Project Documentation

### 🌟 Overview

This is a comprehensive AI-powered disaster relief demand prediction system built using the MERN stack (MongoDB, Express, React, Node.js) with Python-based machine learning components. The system predicts relief resource requirements for disaster-affected areas using multi-source data analysis including social media, weather data, and historical disaster records.

## 🚀 Setup Instructions

### Prerequisites

- **Node.js** (v16 or higher)
- **Python** (v3.8 or higher)
- **MongoDB** (v5.0 or higher)
- **npm** or **yarn**
- **pip** (Python package manager)

### 1. Clone the Repository

```bash
cd swasthyasetu
```

### 2. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Install Node dependencies
npm install

# Create environment file
cp .env.example .env

# Edit .env file with your configuration
# MONGODB_URI=mongodb://localhost:27017/disaster_relief_ai
# PORT=5000
```

### 3. Frontend Setup

```bash
# Navigate to frontend directory
cd frontend

# Install React dependencies
npm install

# Create .env file (optional)
echo "REACT_APP_API_URL=http://localhost:5000/api" > .env
```

### 4. Python ML Pipeline Setup

```bash
# Navigate to project root
cd ..

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install Python dependencies
pip install -r requirements.txt

# Download NLTK data
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords'); nltk.download('wordnet'); nltk.download('averaged_perceptron_tagger')"
```

### 5. MongoDB Setup

```bash
# Start MongoDB service
# On Windows:
net start MongoDB

# On macOS:
brew services start mongodb-community

# On Linux:
sudo systemctl start mongod
```

## 🧠 Machine Learning Pipeline

### Running the Complete ML Pipeline

```bash
# Activate virtual environment
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Run complete pipeline
python ml_pipeline/main_pipeline.py
```

The pipeline will:
1. ✅ Collect historical disaster data
2. ✅ Collect weather-disaster correlation data
3. ✅ Preprocess text data (cleaning, tokenization, lemmatization)
4. ✅ Engineer features for ML models
5. ✅ Train disaster classification model
6. ✅ Train resource prediction model
7. ✅ Save models to `backend/ml_models/`

### Running Individual Components

**Data Collection:**
```bash
python ml_pipeline/data_collection/twitter_scraper.py
python ml_pipeline/data_collection/historical_data_collector.py
python ml_pipeline/data_collection/weather_data_collector.py
```

**Preprocessing:**
```bash
python ml_pipeline/preprocessing/text_preprocessor.py
```

**Feature Engineering:**
```bash
python ml_pipeline/feature_engineering/feature_extractor.py
```

**Model Training:**
```bash
python ml_pipeline/models/disaster_classifier.py
python ml_pipeline/models/resource_predictor.py
```

## 🤖 Machine Learning Models

### 1. Disaster Classifier
- **Type**: Random Forest Classifier
- **Purpose**: Classify disaster type from text/data
- **Features**: Text features (TF-IDF), severity, urgency, engagement metrics
- **Accuracy**: ~85%

### 2. Resource Predictor
- **Type**: Multi-output Random Forest Regressor
- **Purpose**: Predict relief resource quantities
- **Targets**: Food, Water, Medical Aid, Shelter
- **Features**: Disaster type, severity, population, temporal features

## 🎨 Customization

### Adding New Disaster Types:
1. Update `disaster_type_mapping` in `feature_extractor.py`
2. Add to dropdown in `PredictionPage.js`
3. Update base demand in `server.js`

### Modifying ML Models:
1. Edit model parameters in `disaster_classifier.py` or `resource_predictor.py`
2. Retrain: `python ml_pipeline/main_pipeline.py`
3. Models auto-save to `backend/ml_models/`
